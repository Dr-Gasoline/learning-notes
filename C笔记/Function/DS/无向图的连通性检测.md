# 无向图的连通性检测

设顶点编号为 `0～V-1`，边数为 `E`。

- **两点连通**：判断 `u` 能否到达 `v`。
- **整图连通**：从任意顶点出发，所有顶点均可达。
- 以下 `adj[u]` 为邻居列表，`deg[u]` 为邻居数量，`A[i][j]` 为邻接矩阵。

## 1. DFS：深度优先搜索

从起点沿边深入，标记所有可达顶点。

使用邻接表时，时间复杂度为 `O(V+E)`，辅助空间为 `O(V)`，包括递归栈。

```c
bool visited[V];

void dfs(int u) {
    visited[u] = true;

    for (int i = 0; i < deg[u]; i++) {
        int v = adj[u][i];
        if (!visited[v])
            dfs(v);
    }
}

bool connected(int u, int v) {
    for (int i = 0; i < V; i++)
        visited[i] = false;

    dfs(u);
    return visited[v];
}
```

遍历结束后，若所有顶点均被标记，则整图连通。从未访问的顶点再次启动 DFS 可以得到新的连通分量。

## 2. BFS：广度优先搜索

使用队列逐层扩展可达顶点，也适合计算无权图的最短距离。

使用邻接表时，时间复杂度为 `O(V+E)`，辅助空间为 `O(V)`。

```c
bool connected(int u, int v) {
    bool visited[V] = {false};
    int queue[V];
    int head = 0, tail = 0;

    visited[u] = true;
    queue[tail++] = u;

    while (head < tail) {
        int x = queue[head++];

        for (int i = 0; i < deg[x]; i++) {
            int y = adj[x][i];

            if (!visited[y]) {
                visited[y] = true;
                queue[tail++] = y;
            }
        }
    }

    return visited[v];
}
```

顶点应在 **入队时** 标记，避免重复入队。若改用邻接矩阵，DFS、BFS 的时间复杂度通常为 `O(V²)`。

## 3. 并查集

将顶点划分成集合。每加入一条边，就合并两端所在的集合；两个顶点属于同一集合，就表示连通。

适合无向图的多次查询和不断加边，普通并查集不直接支持删边。

```c
int parent[V], size[V];

void init() {
    for (int i = 0; i < V; i++) {
        parent[i] = i;
        size[i] = 1;
    }
}

int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]); // 路径压缩
    return parent[x];
}

void merge(int a, int b) {
    a = find(a);
    b = find(b);

    if (a == b)
        return;

    if (size[a] < size[b])
        swap(a, b);

    parent[b] = a;
    size[a] += size[b];
}

bool connected(int u, int v) {
    return find(u) == find(v);
}
```

先初始化，再对每条边执行 `merge(a, b)`。

采用路径压缩与按大小合并后，单次操作的均摊复杂度为 `O(α(V))`，接近常数；辅助空间为 `O(V)`。

## 4. Warshall：传递闭包

逐个允许顶点作为中间节点，计算所有顶点之间的可达关系。

若 `i` 能到 `k`，且 `k` 能到 `j`，则 `i` 能到 `j`；两段路径本身可以经过多个顶点。

```c
bool reach[V][V];

void warshall() {
    for (int i = 0; i < V; i++) {
        for (int j = 0; j < V; j++)
            reach[i][j] = (i == j) || A[i][j];
    }

    for (int k = 0; k < V; k++) {
        for (int i = 0; i < V; i++) {
            for (int j = 0; j < V; j++) {
                reach[i][j] = reach[i][j]
                           || (reach[i][k] && reach[k][j]);
            }
        }
    }
}
```

- 查询两点连通：读取 `reach[u][v]`。
- 时间复杂度为 `O(V³)`，空间复杂度为 `O(V²)`。
- 此标准写法中，**中间节点 `k` 放在最外层**。
- 相当于把任一条连通路径划分为一个个经过单节点的短路径，再逐步更新，直到覆盖全部的连通关系。
- 适合小图，以及需要保存任意两点可达关系的情况。

## 5. 可达集合迭代扩展

初始只有起点可达，每轮加入所有已可达顶点的邻居，直到集合不再变化。

最多扩展 `V-1` 轮，因为可达的两点之间总存在一条不超过 `V-1` 条边的简单路径。

以下位掩码版本适用于 `V ≤ 64`；`neighbors[i]` 的第 `j` 位为 1，表示 `i` 与 `j` 直接相邻。

```c
uint64_t neighbors[V];

bool connected(int u, int v) {
    uint64_t reach = 1ULL << u;

    for (int step = 0; step < V - 1; step++) {
        uint64_t next = reach;

        for (int i = 0; i < V; i++) {
            if ((reach >> i) & 1ULL)
                next |= neighbors[i];
        }

        if (next == reach)
            break;

        reach = next;
    }

    return ((reach >> v) & 1ULL) != 0;
}
```

- 每轮根据旧集合 `reach` 扩展到 `next`，并保留原有顶点。
- 此版本时间复杂度为 `O(V²)`，每次按位操作视为常数时间。
- 顶点更多时，可使用多字位集合。
- 适合小图、位运算，以及单一起点的可达性计算。
