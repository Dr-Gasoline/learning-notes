# 数字电路运行逻辑

## 1. 线路状态

数字电路中的线路可能表现为以下状态：

- `0`：确定的低电平；
- `1`：确定的高电平；
- `Z`：高阻态，表示当前没有有效驱动；
- `X`：未知态或信号冲突。

高阻态与未知态需要区分：`Z` 表示没有驱动，`X` 表示无法确定或存在冲突。

## 2. 线路与信号源

线路本身不会主动产生或保存信号，只负责连接元件。线路上的逻辑值由信号源或输出元件决定：

```text
信号源输出 → 线路连接 → 后级元件读取
```

因此，线路并非独立地“传递”信号。在线路被有效驱动后，线路上的逻辑值与信号源输出保持一致，可以将其理解为信号源对整条连接网络进行了赋值。

没有有效信号源驱动的线路，可能处于高阻态或未知状态；普通被有效驱动的线路则具有确定的 `0` 或 `1`。

## 3. 仿真开始时的状态

仿真开始前，未被有效驱动的线路可能表现为高阻态或未定义状态。仿真启动后，电路中的信号源开始工作，相关线路逐渐得到确定的 `0` 或 `1`。

需要注意：并不是所有线路在仿真开始前都必然是高阻态。线路的实际状态取决于是否存在有效的驱动源、三态输出以及其他连接关系。

## 4. 时序逻辑

时序逻辑元件能够保存数据，其状态通常由时钟信号控制。寄存器就是典型的时序逻辑元件。

寄存器的基本过程为：

```text
时钟有效边沿到来
        ↓
采样 D 端输入数据
        ↓
寄存器保存该数据
        ↓
更新 Q 端输出
```

许多时序元件具有 `Enable` 或 `Load` 控制端：

- `Enable` 有效：允许元件在时钟边沿更新；
- `Enable` 无效：保持原有状态；
- `Load` 有效：在规定时序下装载输入数据；
- `Load` 无效：不执行装载操作。

因此，数据输入端即使已经变化，只要更新条件没有满足，寄存器输出仍可能保持不变。  

要实现寄存器值的保持，可以考虑 `Enable == 0` 或者 `D = Q` 两种方式。  

## 5. 时钟与边沿触发

时钟信号具有电平和边沿两种重要概念：

- 上升沿：`0 → 1`；
- 下降沿：`1 → 0`；
- 高电平或低电平：表示时钟当前所处的电平状态。

边沿触发元件识别的是电平**变化**，而不是单纯识别时钟保持为 `0` 或 `1`。

## 6. 高阻态与多驱动

三态输出关闭时，其输出为 `Z`，相当于暂时断开，不会主动输出 `0` 或 `1`。

当多个输出端连接到同一条线路时：

- 只有一个驱动源有效：线路通常能够正常工作；
- 所有驱动源都关闭：线路可能处于高阻态；
- 多个驱动源同时输出不同值：可能产生冲突或未知态 `X`。

因此，共享线路必须设计好输出使能关系，避免多个驱动源同时工作，也要避免所有驱动源同时关闭而导致线路悬空（可通过设置上/下拉电阻强行设置线路默认值）。

## 7. 反馈与分阶段时序

在带反馈的时序电路中，组合逻辑根据寄存器当前输出产生新的数据，再反馈到寄存器输入端：

```text
寄存器输出 → 组合逻辑 → 寄存器输入
       ↑                  ↓
       └──── 时钟控制更新 ─┘
```

如果一个较大的工作周期包含多个时序阶段，则可以在不同阶段分别更新不同的存储状态。此时需要明确：

- 下一阶段读取的是旧值还是已经更新的值；
- 各阶段之间是否有足够的组合逻辑传播时间；    

**注意：** 要实现数据的正常更新，输入端的数据更新不得晚于边沿信号端的变化
